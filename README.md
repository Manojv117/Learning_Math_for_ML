📚 Learning Math for Machine Learning

Building a strong mathematical foundation for Machine Learning and AI.

This repository documents my journey of learning the core mathematical concepts required for Machine Learning, along with notes, exercises, and implementations in Python.

The goal is to understand the math behind ML algorithms, not just use libraries.

🚀 Why This Repository?

Machine Learning algorithms rely heavily on mathematics.
Understanding the math helps to:

Understand how algorithms actually work

Debug models effectively

Build new models and research ideas

Become a stronger ML Engineer / AI Engineer

This repo focuses on the essential math pillars used in ML.

🧠 Core Topics
1️⃣ Linear Algebra

Linear Algebra is the backbone of Machine Learning.
It is used in neural networks, dimensionality reduction, and optimization.

Topics covered:

Vectors and vector spaces

Dot product and projections

Matrix operations

Matrix multiplication

Eigenvalues and Eigenvectors

Orthogonality

Matrix decomposition

Singular Value Decomposition (SVD)

Principal Component Analysis (PCA)

📂 Folder: linear-algebra/

2️⃣ Calculus

Calculus helps us understand how models learn and optimize.

Topics covered:

Functions and limits

Derivatives

Partial derivatives

Chain rule

Gradients

Jacobians

Hessians

Optimization

Gradient Descent

Backpropagation intuition

📂 Folder: calculus/

3️⃣ Probability

Probability allows ML models to handle uncertainty and randomness.

Topics covered:

Random variables

Probability distributions

Conditional probability

Bayes theorem

Expectation

Variance

Law of large numbers

Central limit theorem

Markov chains

📂 Folder: probability/

4️⃣ Statistics

Statistics helps evaluate models and interpret data.

Topics covered:

Descriptive statistics

Sampling

Hypothesis testing

Confidence intervals

Maximum Likelihood Estimation (MLE)

Bias vs Variance

Statistical inference

A/B testing
